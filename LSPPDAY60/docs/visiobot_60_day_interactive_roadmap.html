Environment & Hardware Setup

To maintain a "simulation-first, hardware-light" methodology, this section outlines the strictly necessary tools. It details the robust Ubuntu 24.04 software stack required for running ROS2 Jazzy and Gazebo Harmonic, alongside the minimal, low-cost physical electronics needed for the Phase 3 embedded AI integration.

💻

Software Stack

  • ✓
    OS: Ubuntu 24.04 LTS (Noble Numbat)

    Native or Docker environment. WSL2 is possible but Docker on Linux is preferred for GPU passthrough.

  • ✓
    Framework: ROS2 Jazzy Jalisco

    The officially supported LTS release for Ubuntu 24.04. Do not use Humble.

  • ✓
    Simulation: Gazebo Harmonic

    Integrates seamlessly with `ros_gz` bridge for Jazzy.

  • ✓
    Vision & AI: OpenCV & YOLOv8

    Python environment for object detection and CvBridge processing.

🔌

Minimal Hardware Checklist

  • ESP32 Development Board
  • Standard USB Webcam / Laptop Camera
  • Breadboard & Jumper Wires
  • Basic Sensor Options (IMU, Distance)
  • LEDs, Push Buttons, Resistors

Note: No 3D printer required. Physical hardware is strictly for Edge AI/micro-ROS deployment.
