Why your original "ROS + 3D Modeling" plan is weaker

  • 3D modeling (Blender/Fusion) is a separate career track — product design, game dev, CAD. 30 days won't build a portfolio-worthy skill.
  • You already know Fusion 360 basics. For robotics, Gazebo simulation is far more relevant and directly career-applicable.
  • ROS + 3D Modeling have zero cross-pollination — you'd be half-skilled in two unrelated things with no coherent project to show.
  • ROS2 → Computer Vision → Edge AI tells one story to an employer: "I build intelligent robots from hardware to AI." That's compelling.

Docker tip — save yourself hours of setup pain

Your Learning-ROS2 repo already has Docker + GPU acceleration on Manjaro Linux, which is the right instinct. Keep that pattern for all phases. ROS2 + Gazebo + CUDA in Docker means you can reproduce your environment anywhere and won't break your system. Use VS Code Remote Containers extension to code inside the container.
