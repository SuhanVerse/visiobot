LSPP2026: AI-Powered Robotics Roadmap

Suhan Khadka's 60-Day Challenge | June 1 – July 30, 2026

🎯 The "VisioBot" Capstone Goal

Welcome to the AI-Powered Robotics track! This roadmap is meticulously designed for an environment with Ubuntu 24.04 LTS. By Day 60, you will build VisioBot—a robot simulated in Gazebo Harmonic running ROS 2 Jazzy, equipped with YOLOv8 vision, autonomous navigation (Nav2), and controlled via edge AI hand gestures running on an ESP32 (via micro-ROS).

💻 Software Setup (Crucial)

  • OS: Ubuntu 24.04 LTS (Native preferred).
  • ROS Distribution: ROS 2 Jazzy Jalisco (Do not use Humble, it is for Ubuntu 22.04).
  • Simulation: Gazebo Harmonic (Default for Jazzy).
  • Languages: Python, C++, Rust (optional for ESP32).
  • Edge AI Tools: TensorFlow Lite, Edge Impulse.

🔌 Hardware List (Light & Simulation-First)

  • MCU: ESP32 Development Board.
  • Wiring: Breadboard, Jumper Wires, Micro-USB/USB-C Cable, Resistor pack.
  • Sensors: MPU6050 (IMU), HC-SR04 (Ultrasonic).
  • Vision: Standard Laptop Webcam or external USB camera.
  • Note: No 3D printer or heavy chassis required. Hardware is solely for the edge AI controller.
